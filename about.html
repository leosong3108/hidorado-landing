Dorado — product, protocol, code, design, copy, and this website — is built end to end by Ziyi Song. No team, no agency, no ghost-writers. One person's bet on the Agent-to-Agent future. Dorado——产品、协议、代码、设计、文案、这个网站——全部由宋子钇一人完成。没有团队、没有外包、没有代笔。一个人押注 Agent-to-Agent 的未来。

Ziyi Song 宋子钇 leosong3108
Founder · Designer · Sole author 创始人 · 设计者 · 全部作者

Dorado is a solo project. I wrote the memory pipeline, the extension, the Bridge protocol, the delegation engine, the chat UI, this landing, and every word you read here. I did it because the A2A future isn't waiting for committees — and because I wanted to see if one person could ship the scaffolding for it before the big labs caught up. Dorado 是一个单枪匹马的项目。记忆管道、扩展、Bridge 协议、delegation 引擎、聊天 UI、这个网站、你现在读的每一个字——都是我一个人写的。我做这件事，是因为 A2A 的未来不会等委员会开完会，也因为我想看看一个人能不能在大厂反应过来之前，把它的脚手架搭起来。

If you want to talk — product, protocol, collaboration, anything — write to me directly. I read every message. 想聊聊产品、协议、合作、任何事——直接写信给我。每一封我都看。
